# Logo definitivo de Peña Austral

`pena-austral-original.png` conserva exactamente la imagen aportada en `image.png`, con su texto y fondo.

`pena-austral-emblem.png` recorta el árbol y el guitarrista (x:160, y:159, 938 × 758) y elimina el fondo claro mediante una máscara de transparencia. Los valores RGB del recorte se conservan; no se regenera ni redibuja el diseño. Se utiliza en el encabezado junto al texto existente.

`app/favicon.ico` contiene un único icono de 64 × 64, obtenido del mismo emblema con proporciones conservadas.
